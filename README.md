# Finns Fintech Web App

Educational fullstack fintech web application created as an academic and portfolio project.

A premium multi-page financial website with a modern UI, smooth animations, reusable components, and real-time online user tracking.

## Features

- Premium fintech landing page
- Multi-page architecture
- Responsive layout
- Glassmorphism UI
- Smooth animations and parallax
- Login and registration pages
- Profile dashboard
- Banking cards catalog
- Card application form
- Contact page
- Real-time online users counter
- Socket.IO integration
- Node.js + Express backend

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- Socket.IO

## Project Structure

## Installation
```bash
npm install
npm start
```
Open in browser:
```bash
http://localhost:3000
```
## About

The project demonstrates frontend layout design, backend architecture, and real-time client-server communication using WebSocket technology.

Built as a portfolio and educational project to showcase practical fullstack development skills.
